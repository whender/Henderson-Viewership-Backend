# Week 1 major-network day release

User explicitly approved deployment of the reviewed Week 1 candidate on September 12, 2026. Historical Week 1 major-network MAE improves 893K to 840K over 74 games, with five season wins. The full-sample improvement remains below the earlier broad-model 3K gate; this is a user-approved scoped release, not a claim that the broad gate passed. Sunday support is sparse, Monday is redundant, and the benchmark excludes later event overlays. The 2026 preview includes those overlays.

Serving is restricted to NBC/CBS/ABC/FOX/ESPN, September 1–7, 2026 (the supported Week 1), and excludes explicit other weeks. Other dates/networks remain unchanged. A separate versioned coefficient artifact is bound to the existing primary artifact hash. The existing primary, competition model and postgame model stay intact. Existing nonlinear eligibility is based on the original baseline; existing opening/Monday overlays run once after the new points.

Training: run `train_week1_major_days.py` from the backend with the sibling RatingsAndRegression research workspace and original source data present. Research source and metrics are archived here. The 18 point forecasts are in prediction_updates/week1_day_2026.csv. Publish with `python3 publish_week1_day_predictions.py --publish` after verifying deployment; omission of --publish performs a dry run. Publication saves a local backup, preserves old forecasts/timing/error/revision fields and all actuals, and labels revisions retrospective. Intervals use the existing shifted primary-model interval method, not a newly validated interval model.
