# Aligned postgame model

The old postgame artifact already included every primary pregame regressor plus Score Diff, but served only that one regression. It omitted the current exact-network ensemble, nonlinear branch, Week 1 major-network day model and event overlays. This release refits that entire architecture with absolute final score difference added to every learned component. Existing competition inputs and nonlinear eligibility remain pregame-only. The 2025 Colorado feature override saved on the Week 1 game is now honored by the shared feature builder.

Historical rolling fits train only on earlier seasons, seed calibration in 2019 and evaluate 2021–2025. Against the refitted legacy standalone-postgame approach, major-network MAE improves 756.795K to 707.159K; all-network MAE improves 473.785K to 446.070K. Week 1 major-network MAE improves 934.370K to 869.245K, but remains worse than the newly tuned pregame model's 840.187K. Its Week 1 >50% miss rate also rises versus the standalone baseline (9.46% to 12.16%). Alignment fixes the architecture; it is not a guarantee that adding final margin improves every slice or every game. Final margin alone does not capture when a game became uncompetitive.

The full fit uses the saved pregame design matrix and data through 2025. Contract tests require exact equality between every pregame component's feature set and its postgame counterpart after adding Score Diff. The loader binds the postgame artifact to primary, nonlinear and Week 1 pregame artifacts by SHA-256 and rejects stale combinations. Missing, negative, nonfinite or fractional scores cannot produce postgame forecasts. Zero is valid. Tests verify postgame actual viewership is not an input, changing scores never affects pregame predictions, and shared row overrides apply correctly.

Historical benchmarks exclude the later serving-only event overlays; serving retains them. Postgame-specific earlier-fold rank calibration and refitted smearing are used. The revised model uses final scores intentionally, so these are explanatory postgame estimates, not forecasts available before kickoff. No 2026 audience data is used in fitting or candidate selection.
